# E-Commerce-analysis

End-to-end analysis of ~100k Brazilian e-commerce orders (Olist, 2016–2018), covering delivery performance, revenue, customer satisfaction, payments, and seller performance, built with pandas, PostgreSQL, and Power BI. Created an ETL pipeline to load data in SQL. 

Business Questions
1.Which states have the longest delivery delays, and does delay correlate with review score?
2. Which product categories drive the most revenue, and which have the highest order value?
3. What's the average review score by state, and what's driving low scores?
4. What payment methods/installment plans do customers prefer, and does installment count affect order value?
5. Which sellers/regions have the best delivery and review performance?

Dashboard Pages
1. Delivery Performance

4. Payment Behavior

Key Finding:
Delivery delay is the strongest driver of low review scores across states, categories, and sellers
